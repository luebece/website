# 정보처리기사 실기 5일 합격 훈련기

정보처리기사 실기 2022년 1회부터 2026년 1회까지 공개된 복원 범위를 학습용으로 재구성한 정적 웹 앱입니다. 13회차 260문항의 요구 기술을 왕초보 설명과 동급 변형문제에 연결하며, 기출 문장을 그대로 복제하지 않습니다.

공개 앱: [https://luebece.github.io/website/](https://luebece.github.io/website/)

## 주요 기능

- 5일 학습 계획과 오늘 복습, 오답, 숙련도 추적
- 551개 왕초보 이론 문제와 C, Java, Python, SQL 코드 입문서
- 전체 자동채점 대상 1,137개와 260/260 기출 범위 연결
- 용어형, 숫자형, 출력형, 순서형, 복수답형별 엄격 채점
- 코드 7문항, SQL/DB 4문항, 이론 9문항의 20문항 모의고사
- 균등 추출 `실전 표준`과 오답·복습 가중치 기반 `약점 집중` 모드
- 모의고사 이어 풀기, 회차별 상세 이력, 영역 분석, 표준 모드 최고점
- JSON 학습 기록 내보내기·가져오기
- PWA 설치와 오프라인 재실행

## 실행

가장 간단한 방법은 공개 앱 주소를 여는 것입니다. 내려받은 배포 ZIP은 압축을 모두 푼 뒤 `index.html`을 Chrome이나 Edge에서 열면 핵심 학습 기능과 기록 저장을 사용할 수 있습니다.

서비스 워커와 설치형 PWA까지 로컬에서 확인하려면 저장소 루트에서 정적 서버를 실행합니다.

```powershell
python -m http.server 8000
```

그다음 `http://127.0.0.1:8000/index.html`에 접속합니다.

## 휴대폰에서 앱처럼 쓰기

- Android Chrome: 메뉴에서 `홈 화면에 추가` 또는 `앱 설치`
- iPhone Safari: 공유 버튼에서 `홈 화면에 추가`

학습 기록은 브라우저의 `localStorage`에 저장됩니다. PC와 휴대폰, 서로 다른 브라우저의 기록은 자동 동기화되지 않으므로 대시보드의 `기록 내보내기`와 `기록 가져오기`로 옮깁니다.

## 처음 공부하는 순서

1. `왕초보 이론서`의 최우선 카드에서 한 줄 설명과 예시를 읽습니다.
2. `코드 입문서`에서 언어별 읽는 순서와 변수표를 따라갑니다.
3. 읽은 내용은 바로 `훈련장`에서 한 문제씩 풉니다.
4. 틀린 문제는 `오답만`과 `오늘 복습`으로 다시 풉니다.
5. `기출 260 커버`에서 회차별 연결 학습이 빠지지 않았는지 확인합니다.
6. `약점 집중`으로 부족한 부분을 보완한 뒤 `실전 표준` 점수를 비교합니다.

## 검사와 배포본

```powershell
npm.cmd test
npm.cmd run test:e2e
npm.cmd run build:release
```

- `npm.cmd test`: 1,137개 답안 채점, 고의 오답, 복합 답안 누락, 역순 답안, 중복 ID, 260개 연결과 캐시 버전을 검사합니다.
- `npm.cmd run test:e2e`: 실제 Chromium에서 저장·복원, 모의고사 구성, 제출 원자성, 이력과 브라우저 오류를 검사합니다.
- `npm.cmd run build:release`: 사용자용 `dist/jeongcheogi-trainer.zip`을 만듭니다.
- GitHub Actions는 위 검사와 사용자용 ZIP 생성을 반복하고 GitHub Pages를 배포합니다.

## 범위와 점수 주의

`기출 260 커버`는 공개 복원 자료를 기준으로 정리했으므로 공식 원문과 표현이나 세부 내용이 다를 수 있습니다. 자동채점은 앱 안에서 일관되게 연습하도록 만든 기준이며 실제 시험의 서술형 부분점수를 그대로 재현하지 않습니다. 이 앱만으로 미래 시험의 100% 합격을 보장할 수는 없고, 표준 모의고사 점수도 실제 시험 예상 점수가 아닙니다.

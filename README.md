# 정보처리기사 실기 5일 합격 훈련기
정보처리기사 실기 2022년 1회부터 2026년 1회까지 공개된 복원 범위를 합쳐 만든 학습 앱입니다.
13회차 260문항의 요구사항을 관련 왕초보 설명과 동급 변형문제에 모두 연결했습니다. 기출 문장은 그대로 복제하지 않습니다.

## 실행

브라우저에서 `index.html`을 열면 됩니다.

검증용 로컬 서버가 켜져 있다면 아래 주소로 접속합니다.

```text
http://127.0.0.1:8000/index.html
```

## 휴대폰 홈 화면 앱처럼 쓰기

GitHub Pages처럼 HTTPS로 배포한 주소에 접속하면 휴대폰 홈 화면에 앱 아이콘처럼 추가할 수 있습니다.

- Android Chrome: 메뉴에서 `홈 화면에 추가` 또는 `앱 설치`
- iPhone Safari: 공유 버튼에서 `홈 화면에 추가`

앱처럼 열리도록 `manifest.webmanifest`, `sw.js`, `pwa.js`, 아이콘 파일이 포함되어 있습니다.
학습 기록은 브라우저별 `localStorage`에 저장되므로 PC와 폰 기록은 따로 관리됩니다.

## 구성

- `대시보드`: 5일 계획, 학습률, 오답 현황
- `왕초보 이론서`: 600개 이상 이론 카드, 한 줄 정의, 처음 보는 법, 예시, 연결 문제
- `코드 입문서`: C, Java, Python, SQL을 한 줄씩 읽는 법, 변수표 추적, 기본 문법, 실전 함정
- `코드 정복판`: 포인터, 동적 배열, 연결 리스트, 함수 포인터, 상속, 예외, 제네릭, 슬라이싱, SQL 실행 순서
- `통합 범위`: 22-1부터 26-1까지의 핵심 범위와 우선순위
- `기출 260 커버`: 13회차 260문항의 요구 기술과 연결된 설명 및 동급 문제 확인
- `훈련장`: 312개 기출급 변형문제를 포함한 이론, SQL, C/Java/Python, 네트워크/OS, 보안 훈련
- `모의고사`: 코드 7문항, SQL/DB 4문항, 이론 9문항으로 구성하는 20문항 실전형 연습
- `5일 루틴`: 시험 직전 압축 루틴

## 아무것도 모르면 이렇게 씁니다

1. `왕초보 이론서`에서 `최우선` 카드부터 봅니다.
2. 한 카드에 3분 이상 붙잡히지 않습니다.
3. `한 줄`, `왜 시험에 나와?`, `처음 보는 법`, `예시` 순서로 읽습니다.
4. 코드 파트는 `코드 입문서`에서 언어별 `정복 루틴`과 `변수표`를 먼저 따라갑니다.
5. `기출 260 커버`에서 회차별로 빠진 연결이 없는지 확인합니다.
6. 읽은 카드는 바로 `이후 한 문제` 또는 `이 언어 문제 풀기`로 훈련장에 보냅니다.
7. 틀린 문제는 `오답만` 모드로 다시 풀어 정답 문장을 외웁니다.

## 이론 문제만 대비할 때

`훈련장`의 `이론문제` 모드를 사용합니다.
이 모드는 코드 출력형을 빼고, `왕초보 이론서`의 설명을 정답 문제로 바꿔 냅니다.

## 코드와 SQL까지 정복할 때

`코드 입문서`에서 C, Java, Python, SQL을 언어별로 봅니다.
각 언어는 다음 순서로 구성되어 있습니다.

- 읽는 순서
- 쓰는 순서
- 핵심 문법
- 변수표로 해독하기
- 실전 템플릿
- 자주 낚이는 함정
- 정복 루틴

학습 기록은 브라우저 `localStorage`에 저장됩니다.

## 콘텐츠 품질 검사

`npm.cmd test`를 실행하면 전체 채점 대상 1,137개에 대해 정상 정답, 정답을 감싼 고의 오답, 숫자 부호와 소수점, 순서형 역순, 중복 ID, 260개 기출 연결을 검사합니다.

## 범위에 대한 주의

`기출 260 커버`의 260문항은 공개 복원 자료를 기준으로 정리한 것입니다. 복원 자료는 공식 원문과 표현이나 세부 내용이 다를 수 있고, 아직 공개되지 않은 미래 시험의 출제를 보장할 수는 없습니다. 앱의 목표는 과거 복원 문항을 외우게 하는 것이 아니라 같은 풀이 기술을 새 문제에도 적용하게 만드는 것입니다.

자동채점은 용어형, 출력형, 순서형, 복수답형을 구분하며 부호와 소수점 및 순서를 보존합니다. 다만 실제 시험의 서술형 부분점수를 재현하지 않으므로 앱 점수를 실제 시험 예상 점수로 해석하면 안 됩니다.

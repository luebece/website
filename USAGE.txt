정보처리기사 실기 5일 합격 훈련기 - 사용법
================================================

1. 이 ZIP의 압축을 폴더에 모두 풉니다.
2. 폴더 안의 index.html을 Chrome 또는 Edge로 엽니다.
3. 처음에는 왕초보 이론서와 코드 입문서를 읽고, 바로 훈련장 문제를 풉니다.
4. 틀린 문제는 오답만 또는 오늘 복습에서 다시 풉니다.
5. 약점 집중 모의고사로 부족한 부분을 연습한 뒤 실전 표준 A~E형 점수를 확인합니다.

모의고사
---------
- 실전 표준 A~E형은 같은 형을 선택하면 항상 같은 20문항이 나옵니다.
- 앱이 업데이트돼도 A~E형 v1의 문항은 바뀌지 않으며, 같은 형과 같은 버전끼리 점수를 비교합니다.
- 각 형은 C 3문항, Java 3문항, Python 1문항, SQL 2문항, DB 2문항, 이론 9문항입니다.
- 코드문법형 문제는 대소문자와 (), <>, -> 같은 기호까지 정답 그대로 써야 합니다.
- SQL문법형은 COUNT, LIKE 같은 예약어의 대소문자는 자유지만 따옴표 안 값은 정확히 써야 합니다.

학습 기록
---------
- 기록은 현재 브라우저 안에 저장됩니다.
- 브라우저 데이터를 삭제하면 기록도 사라질 수 있습니다.
- 대시보드의 기록 내보내기로 JSON 백업 파일을 만들고, 기록 가져오기로 복원할 수 있습니다.
- PC와 휴대폰 기록은 자동 동기화되지 않습니다.

휴대폰에서 앱처럼 사용하기
--------------------------
공개 주소 https://luebece.github.io/website/ 에 접속합니다.
- Android Chrome: 메뉴 > 홈 화면에 추가 또는 앱 설치
- iPhone Safari: 공유 > 홈 화면에 추가

참고
----
- index.html을 직접 열어도 핵심 학습과 기록 저장은 동작합니다.
- 설치형 앱과 오프라인 캐시는 위 공개 HTTPS 주소에서 사용하는 것이 가장 안정적입니다.
- 앱 점수는 실제 시험 합격을 보장하는 예측 점수가 아닙니다.
